Web mai Chart X 擴充程式開發者手冊

手冊定位與適用對象

本網站提供 Web mai Chart X 擴充程式系統的官方開發介面與封裝規格，協助開發者建立客製化視覺圖層、譜面輔助工具、介面面板與素材覆寫擴充程式。

每個詞條頁面皆提供獨立靜態 HTML 與對應純 Markdown 檔案，無須執行 JavaScript 即可直接讀取全部內容。

執行環境信任模型與保留欄位警示

warning 主執行緒執行與 runtime: worker 未實作
  • 所有擴充程式皆以動態 ESM 匯入並執行於瀏覽器主執行緒，無系統級安全沙盒隔離，可存取並修改頁面 DOM 與讀取專案資料。
  • 注入進入點的 ctx 受限上下文物件屬於官方介面層級的權限控管與資源追蹤機制。
  • manifest.json 中的 runtime: "worker" 目前為保留但未實作欄位；嘗試啟用設定為 worker 的擴充程式會立即進入錯誤狀態並拒絕執行。

逐幀離線錄影渲染機制

Web mai Chart X 的譜面影片匯出採用固定幀率逐幀離線渲染，並非即時螢幕擷取。於 ctx.render.registerOverlay 設定 target: "main" 且 includeInVideo: true 的圖層會被納入輸出影片。

離線渲染期間不依賴 requestAnimationFrame，也不應使用 Date.now() 或 performance.now() 推算動畫進度，所有視覺效果必須完全依據傳入的 globalTime 計算。
