隱私權政策

版本：2026-11-16 · 最後更新：2026 年 11 月 16 日

本隱私權政策說明當您使用 Web mai Chart X 網頁應用程式、其相關功能以及 Google Drive 整合服務時，Web mai Chart X 如何處理與保護相關資訊。

1. Web mai Chart X 的服務內容

Web mai Chart X 是一款基於網頁瀏覽器運作的音樂遊戲譜面編輯工具。本應用程式可選擇性整合 Google Drive，讓使用者在自己的 Google Drive 中建立、儲存、下載與開啟 Web mai Chart X 專案檔案； 同時亦提供瀏覽器本地儲存、離線快取、外部公開譜面庫查詢、本機模擬器連線同步，以及插件與擴充功能系統。

2. 我們存取的資訊

Google 帳戶資訊

當您使用 Google 帳戶登入時，Google 可能會提供驗證您身分所需的基本帳戶資訊，例如您的 Google 帳戶識別碼與基本個人資料。

Web mai Chart X 不會要求存取您的 Gmail、聯絡人、Google 相簿或其他與本服務功能無關的 Google 服務。

Google Drive 資料

若您啟用 Google Drive 整合功能，Web mai Chart X 將請求下列 Google OAuth 權限：

  • drive.file：僅允許本應用程式存取透過 Web mai Chart X 建立或由您明確開啟的特定 Google Drive 檔案。
  • drive.install：允許 Web mai Chart X 與 Google Drive 的應用程式及開啟方式功能進行整合。

本應用程式僅將 Google Drive 存取權限用於提供本政策所述之雲端專案功能。

瀏覽器本地儲存資料

為了支援離線使用與編輯紀錄保存，本應用程式會在您的瀏覽器本地端儲存下列資料：

  • 透過 IndexedDB 儲存的譜面專案、音訊、圖片與封裝資源。
  • 透過 localStorage 儲存的編輯器偏好設定、介面語言與服務條款及隱私權政策同意紀錄。
  • 透過 Service Worker 儲存的應用程式離線快取資源。

3. 我們如何使用資訊

相關資訊與 Google Drive 資料僅用於下列用途：

  • 驗證您的 Google 帳戶身分。
  • 於 Google Drive 中建立與管理 Web mai Chart X 專案檔案。
  • 下載由您主動選取之專案檔案。
  • 從 Google Drive 開啟 Web mai Chart X 專案檔案。
  • 提供由您明確請求的同步與雲端儲存功能。
  • 維持並改善本應用程式的功能性與安全性。

我們絕不會將您的 Google Drive 資料用於廣告、精準廣告投放、使用者剖析、信用評估或任何無關之服務。

4. 資料處理與外部連線方式

Web mai Chart X 主要為前端用戶端網頁應用程式，不會營運永久儲存您 Google Drive 專案複本的官方後端資料庫。 Google Drive 檔案係透過 Google 官方應用程式介面直接在您的瀏覽器與 Google 服務之間傳輸，並於您的瀏覽器端進行解析與編輯。

當您使用特定選用功能時，瀏覽器將依您的操作發起下列連線：

  • 外部公開譜面資料庫：當您主動查詢或下載公開譜面清單時，瀏覽器會向第三方 Supabase 資料庫發起查詢與檔案下載請求。
  • 本機模擬器連線：當您啟用 MajdataView 連線同步時，瀏覽器會透過本機迴路 WebSocket 將譜面狀態、設定與檔案路徑傳送至您裝置上執行的本機軟體，該資料不會傳送至官方伺服器。
  • 網站託管與字型資源：本網站透過靜態網站託管服務提供，並向 Google Fonts 載入字型與圖示資源； 依網際網路通訊標準，連線請求可能包含您的網際網路協定位址與瀏覽器標頭資訊。

5. 第三方插件與擴充功能

Web mai Chart X 提供或未來可能提供的插件系統，允許使用者自行安裝並啟用第三方開發之插件。 插件在瀏覽器中運行時，可能依其宣告並經您核准的權限，透過官方介面讀取或修改編輯器內的譜面內容、 專案資源、外觀貼圖或應用程式設定。請注意，權限機制主要用於宣告插件用途與控管官方應用程式介面之存取， 並非完全隔離的系統級安全沙盒；由於插件係與本應用程式運行於同源瀏覽器環境中， 該機制無法從技術上完全阻絕惡意程式碼直接讀取瀏覽器本地儲存資料或自行發起網路連線。 因此，請勿安裝或載入來路不明之插件，並請妥善保管個人資料與第三方金鑰。

部分插件可能會請求您提供外部服務金鑰，或將譜面資料與輸入內容傳送至第三方網路服務或人工智慧介面。 該等資料收集、傳輸與處理行為完全受該插件開發者及對應外部服務提供者之隱私權政策規範， 不受 Web mai Chart X 控管，亦不適用本政策中有關 Google 使用者資料限制使用之規定。 請於安裝或授權任何第三方插件前，自行審慎評估其安全性與隱私風險。

我們不會將您的 Google Drive 資料出售、出租或提供給廣告商、資料仲介商或其他無關第三方。

8. 資料保留

您可以隨時透過您的 Google 帳戶安全性設定，撤銷 Web mai Chart X 對您 Google 帳戶的存取權限。 撤銷權限後，需要 Google 授權的雲端硬碟整合功能將立即停止運作，直到您再次授權為止。

Web mai Chart X 與 Google 服務通訊時一律使用 HTTPS 加密傳輸。OAuth 存取權杖僅於瀏覽器端處理， 不會刻意儲存於 Web mai Chart X 的伺服器端資料庫。

然而，任何電子傳輸或儲存方式皆無法保證百分之百安全。請您亦妥善保護您的 Google 帳戶、裝置存取權限， 以及於插件中自行輸入之任何第三方金鑰。
